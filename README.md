# Radiance Cascades Compared to Unity's Standard Global Illumination Methods



Experiment materials for the paper **"Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP"** (DiGRA conference).



## About the project

This project compares **Radiance Cascades**, a newer real-time global illumination technique, with Unity's standard global illumination methods in URP.

The comparison looks at:

- **Performance**: FPS and frame time

- **Visual quality**: recorded render videos
